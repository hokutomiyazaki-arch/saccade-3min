# サッカード3分 ─ 眼の下地づくり（FNT Lite PWA）

点が上下・左右・斜め・ランダムに飛ぶのを、顔を固定して眼だけで追う3分固定のサッケード。
点の中の1桁の数字（1〜9）を足していき、最後に合計を答える。
カラダマニア「7【指導者の盲点】その指導、動きの"下地"を何も作っていません（動体視力・サッケード）」の配布アプリとして作成（2026-09-28・宮崎さん指示）。LINE配布ワード＝**サッカード**。

## 仕様（宮崎さん指定）
- **3分固定・設定なし**。上下 → 左右 → 斜め → ランダム を各45秒。
- 点は1.2秒ごとに飛ぶ（3分で150回）。斜めは前半が左上↔右下、後半が右上↔左下。ランダムは8か所から、直前と違う場所。
- 点の中に1桁の数字（1〜9。直前と同じ数字は出さない）。終わったら合計をテンキーで答える → 正しい合計・ずれを表示。「わからない」で答えだけ見られる。
- どの時刻にどこへ何が出るかは開始時に全部決める（一時停止しても崩れない）。
- パターンの切り替わりは画面の表示＋音声（TTS）でお知らせ。音声オフでも表示だけで進む。

## FNT標準
3ファイル構成（index.html / manifest.json / sw.js）・Network First＋controllerchange自動リロード・スプラッシュ（起動時だけ）・☰サイドメニュー（神経科学の解説・指導者の方へ）・M PLUS Rounded 1c・Date.now()の壁時計・一時停止中は時間を足さない・画面が隠れたら自動で一時停止・Wake Lock・AudioContextのtry-catch＋警告バナー・アプリ専用アイコン5点・著作権表記。

## ローカルで動かす
```
cd ~/FNT-Apps/saccade-3min
python3 -m http.server 8779
```
デプロイのたびに `sw.js` の `CACHE_NAME` を上げる。
